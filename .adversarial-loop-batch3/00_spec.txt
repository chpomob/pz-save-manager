## Fix required

### 1. Hide traceback from index() error response (A4)
In `gui.py`, the `index()` function currently returns the full `format_exc()` traceback in the HTML response on failure. This discloses absolute filesystem paths, usernames, package versions, and internal stack structure to any client.

The logging is already correct (the traceback IS logged via `logging.getLogger(__name__).error(...)`). The fix is to return only a generic message to the client, while keeping the detailed traceback in the server logs.

Change the error return in `index()` from:
```python
return (
    "<!doctype html><meta charset='utf-8'><style>...</style>"
    "<h2>PZ Save Manager — Error</h2>"
    "<p>The UI failed to load. Check the console for details.</p>"
    "<p>Try <a href='/health' style='color:#e94560'>/health</a> for diagnostics.</p>"
    f"<pre>{escape(tb)}</pre>"
), 500
```

To:
```python
return (
    "<!doctype html><meta charset='utf-8'><style>body{font-family:monospace;background:#111;color:#eee;padding:2rem}pre{white-space:pre-wrap;background:#222;padding:1rem;border-radius:6px;overflow-x:auto}</style>"
    "<h2>PZ Save Manager — Error</h2>"
    "<p>The UI failed to load. The full error has been logged to the console.</p>"
    "<p>Try <a href='/health' style='color:#e94560'>/health</a> for diagnostics, or run with <code>pz-saves gui --debug</code> to see the traceback.</p>"
), 500
```

Keep the `format_exc()` and `logging.error(...)` lines unchanged — they're already correct.
