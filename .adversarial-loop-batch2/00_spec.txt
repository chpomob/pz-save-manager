## Fixes required

### 1. Make api_config atomic (B5)
In `routes_api.py`, `api_config()` line ~199-231 — the function persists each valid key immediately while still collecting errors. If a request has `{"backups_dir": "/tmp", "debounce_seconds": "invalid"}`, the backups_dir change IS persisted before the 400 is returned.

Fix: first validate and coerce ALL keys into a temporary dict. Only persist (via `_config_store().set()`) if no errors exist:
```python
from .config import _coerce

allowed = {"backups_dir", "debounce_seconds", "backup_cooldown_minutes", "max_auto_backups", "port", "auto_start_watcher"}
pending: dict = {}
errors: dict[str, str] = {}
for key, value in data.items():
    if key not in allowed:
        continue
    if value is None or value == "":
        if key == "backups_dir":
            pending[key] = None
        continue
    try:
        pending[key] = _coerce(key, value)
    except (ValueError, TypeError):
        errors[key] = f"Invalid value for {key}"
if errors:
    return jsonify({"ok": False, "error": "Invalid values", "fields": errors}), 400
for key, value in pending.items():
    _config_store().set(key, value)
return jsonify({"ok": True, "message": "Settings saved", "config": _config_store().get_all()})
```

### 2. Add validation to prune_auto_backups (B6)
In `backup.py`, `prune_auto_backups()` line ~370-411 — the function builds `root / game_mode / save_name` without calling `_validate_component`. The only caller (`create_backup`) validates first, but the public function should be self-defensive.

Add at the start of the function:
```python
_validate_component(game_mode, "game mode")
_validate_component(save_name, "save name")
```

### 3. Fix GUI max_auto_backups min=1 -> min=0 (B7)
In `templates/index.html`, the settings input for max_auto_backups (line ~149) has `min="1"`. The backend (config.py `_coerce`) and tests support `max_auto_backups=0` (disables pruning). Change `min="1"` to `min="0"` and update the help text from "Min interval between backups" to show that 0 disables pruning.

The input on line 149:
```html
<input id="cfg-max-auto" type="number" step="1" min="1" max="999" ...>
```
Change `min="1"` to `min="0"`.

### 4. Fix version consistency (B8)
In `__init__.py`, `__version__ = "0.2.0"` while `pyproject.toml` declares `0.3.0`. The `/health` endpoint reports `__version__`. Update `__version__` to `"0.3.0"` to match pyproject.toml.
